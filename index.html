Selected Projects

ERNIE: Enhanced Representation through Knowledge Integration
Core Developer
GitHub Stars: 7.6k+ | Foundation Models similar to Gemini/ChatGPT
A series of industrial-grade Large Language Models (LLMs) and multimodal foundation models. Features include Mixture-of-Experts (MoE) architecture, cross-modal reasoning, and high-performance pre-training. Widely used in industrial applications.

TimeCraft: A Universal Framework for Time-Series Generation
Researcher / Contributor
GitHub Stars: 1.3k+ | Developed by Microsoft Research Asia
A foundation model framework for Time-Series Generation using diffusion models. It allows users to generate synthetic time-series data (e.g., market behavior, medical trends) using plain language descriptions, achieving strong cross-domain generalization.
